# Лабораторная работа 2. ETL для SQLite

## Автор
Булатова С.И., группа 301 

## Описание
Скрипт `make_db_init.py` читает CSV/TXT-файлы из `dataset` и генерирует SQL-скрипт `db_init.sql` для создания таблиц и загрузки данных в базу `movies_rating.db`.

## Требования к окружению
- **Python v.3** (команда `python` доступна в PATH).
- **SQLite 3** (команда `sqlite3` доступна в PATH).
- ОС: Windows, Linux, macOS.

## Запуск
```bash
bash db_init.bat
